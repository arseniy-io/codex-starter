# Local Codex skills

Клади сюда только skills, которые нужны именно этому репозиторию.

Формат одного skill:

```
.agents/skills/
└── skill-name/
    ├── SKILL.md
    ├── scripts/
    └── assets/
```

Перед установкой любого skill проведи аудит: `README.md`, `SKILL.md`, scripts, внешние URL, доступ к `.env`, операции удаления.
