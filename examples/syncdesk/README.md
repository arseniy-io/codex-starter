# SyncDesk example

Вымышленный пример заполненного `ai-clone/` для технического фаундера B2B SaaS.

Он нужен как демонстрация уровня детализации после `POST_AUTOPILOT.md`. Не копируй эти формулировки в реальный проект без адаптации: корневой `ai-clone/` в starter остаётся нейтральным placeholder-слоем.
