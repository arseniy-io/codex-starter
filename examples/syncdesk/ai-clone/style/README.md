# Style

## Интерфейс

SyncDesk должен выглядеть как рабочий SaaS-инструмент: плотная сетка, понятные статусы, таблицы, ленты событий, фильтры, role-aware действия. Без маркетинговых hero-экранов внутри продукта.

## Тексты

- Короткие заголовки.
- Конкретные статусы вместо эмоциональных обещаний.
- Важные ограничения рядом с действием.
- Security-тексты без громких claims.

## Документы

Фаундер любит структурированные документы, но не архив ради архива. Хороший файл отвечает на вопрос, зачем его читать перед задачей.

## Предпочтение

Лучше один ясный `roadmap.md`, чем пять файлов "на будущее". Но если один файл начинает смешивать роли, интеграции и security, нужно разделить.
