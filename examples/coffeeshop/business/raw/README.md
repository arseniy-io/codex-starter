# Raw-источники

Сюда складываются исходники: транскрипции интервью, переписки, выгрузки POS/CRM, заметки с планёрок, скриншоты аналитики и другие материалы, из которых потом делаются короткие выводы в `business/`.

`raw/` не входит в стартовый маршрут чтения. Codex открывает конкретный raw-файл только если задача требует проверить первоисточник.
