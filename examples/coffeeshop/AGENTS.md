# AGENTS.md - Coffee Place example

## Проект

**Coffee Place** - вымышленная сеть кофеен в Казани с мобильным приложением, программой лояльности и подпиской Coffee Monthly.

Подробный контекст - в `.business/INDEX.md`.

## Стек

Примерный стек: mobile app + backend API + PostgreSQL/Prisma. Точный стек в примере не является рекомендацией.

## Как работать

1. Для продуктовых решений сначала читай `.business/INDEX.md`, затем только нужные файлы из `.business/`.
2. Для новой функции создай план в `plans/YYYY-MM-DD-название.md`.
3. Перед реализацией крупной функции прогони план через 3 независимых ревью: техника, бизнес, UX.
4. После реализации обнови план и запиши, какие проверки прошли.
5. После заметной сессии создай ретро в `retrospectives/YYYY-MM-DD_HH-MM_название.md`.
6. Не коммить реальные `.env`, персональные данные клиентов или приватные документы бизнеса.
