# AGENTS.md - Coffee Place example

## Проект

**Coffee Place** - вымышленная сеть кофеен в Казани с мобильным приложением, программой лояльности и подпиской Coffee Monthly.

Подробный контекст - в `business/INDEX.md`.

## Стек

Примерный стек: mobile app + backend API + PostgreSQL/Prisma. Точный стек в примере не является рекомендацией.

## Как работать

1. Для продуктовых решений сначала читай `business/INDEX.md`, затем только нужные файлы из `business/`.
2. Если задача про выручку, цены, клиентов, конверсии или даты, сначала читай `business/life-metrics.md`.
3. Не читай весь `business/`, `business/raw/`, `ai-clone/` или `mastery/` без явной причины.
4. Для новой функции создай план в `plans/YYYY-MM-DD-название.md`.
5. Перед реализацией крупной функции прогони план через 3 независимых ревью: техника, бизнес, UX.
6. После реализации обнови план и запиши, какие проверки прошли.
7. После заметной сессии создай ретро в `retrospectives/YYYY-MM-DD_HH-MM_название.md`.
8. Не коммить реальные `.env`, персональные данные клиентов или приватные документы бизнеса.
