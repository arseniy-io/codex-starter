# Experiments

Папка для новых проверяемых stress-tests, гипотез и сравнительных прогонов starter.

Старые отчёты разработки самого starter лежат в `maintainer/history/experiments/`, чтобы чистая папка `experiments/` не выглядела как обязательный контекст для каждого нового проекта.

## Как пользоваться

- Храни здесь только временные или исследовательские артефакты.
- Не считай `experiments/` постоянным источником истины для проекта.
- После эксперимента переноси устойчивые выводы в `AUTOPILOT.md`, `POST_AUTOPILOT.md`, `AGENTS.md`, `templates/` или `QUALITY_CHECKLIST.md`.
- Если эксперимент больше не нужен для текущей работы, перенеси его в `maintainer/history/experiments/` или удали отдельной осознанной правкой.
