# Experiments

Папка для проверяемых стресс-тестов, гипотез и сравнительных прогонов starter.

## Как пользоваться

- Храни здесь только временные или исследовательские артефакты.
- Не считай `experiments/` постоянным источником истины для проекта.
- После эксперимента переноси устойчивые выводы в `AUTOPILOT.md`, `POST_AUTOPILOT.md`, `AGENTS.md`, `templates/` или `QUALITY_CHECKLIST.md`.
- Если эксперимент больше не нужен, его можно архивировать или удалить отдельной осознанной правкой.
