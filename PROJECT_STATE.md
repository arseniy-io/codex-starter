# PROJECT_STATE

## Проект

**Codex Starter / AUTOPILOT** - стартовая методология для проектов разной сложности, чтобы Codex быстро понимал проект в новом контекстном окне и не тратил лишние токены на чтение всей папки.

## Текущий фокус

В P1 завершены Фазы 0-4, Фаза 5 находится на локальной подготовке релиз-кандидата v1.0.0. Основной способ получить свою копию - GitHub Template, запасной - ZIP стабильной версии. Публичный первый экран ведёт через три действия, а раздел безопасности отделяет реальные проверки от механизмов, которые требуют ручного trust или установки.

Единая команда выпуска проверяет структуру, три контрольных результата онбординга, безопасную очистку и известные утечки; CI повторяет её на Windows и Linux. Живая приёмка отдельно пройдена на `lite`-проекте с Git и `deep`-проекте без Git. Новые окна сразу поняли оба очищенных проекта и не запустили Starter повторно. Проверка паузы внутри интервью нашла и закрыла потерю частичного ответа: теперь краткий безопасный смысл записывается до следующего вопроса, а новое окно продолжает с первого незавершённого места. Граница поддержки v1 пока узкая: Codex desktop app на Windows, нативный PowerShell и проект на файловой системе Windows. Пользовательский AUTOPILOT в основном проекте не запускался.

## Читать по задаче

- `business/INDEX.md` - если задача про продукт, аудиторию, UX, ценность или бизнес-контекст.
- `business/life-metrics.md` - если задача про живые цифры, метрики, цены, выручку, клиентов или конверсии.
- `ai-clone/INDEX.md` - если задача про голос, стиль, личные предпочтения или устойчивые ошибки.
- `mastery/INDEX.md` - если задача про методологию, discovery или экспертный подход.
- `experiments/README.md` - если задача про новый stress-test или гипотезу.
- `maintainer/README.md` - если задача про историю решений и старые прогоны самого starter.
- `autopilot/NEW_WINDOW_TEST.md` - если задача про проверку поведения Codex в новом окне перед публикацией starter.

## Не читать без причины

- весь `business/`;
- весь `ai-clone/`;
- весь `mastery/`;
- все планы и ретро;
- `maintainer/history/`, если задача не про прошлые решения starter;
- тестовые копии на рабочем столе как источник истины.
