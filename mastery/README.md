# Mastery

`mastery/` - личный совет директоров проекта: концентрат методов лучших авторов и практиков по областям, которые реально нужны в работе.

Правило структуры:

- одна папка = одна область;
- один файл = один автор, практик или школа мышления;
- внутри файла - 1-3 метода: суть, когда применять, шаги, ограничения.

Не храни здесь пересказы книг и длинные копии источников. Ценность `mastery/` - в коротких применимых методах, которые Codex может быстро взять под задачу.
