# Mastery

Эта папка хранит не знания "вообще", а применимые методы.

## Что сюда класть

- методологии экспертов;
- рабочие фреймворки;
- правила анализа;
- алгоритмы принятия решений;
- выдержки из собственных материалов, если они превращены в метод.

## Что сюда не класть

- пересказы книг;
- длинные статьи без алгоритма;
- мотивационные заметки;
- приватные данные клиентов;
- секреты и ключи.

## Формат файла метода

```md
# Название метода

## Автор или источник

Кто сформулировал подход и почему ему можно доверять.

## Суть

Коротко: что делает метод.

## Когда применять

Ситуации, где метод полезен.

## Как применять

1. Шаг.
2. Шаг.
3. Шаг.

## Ограничения

Когда метод не подходит.
```
