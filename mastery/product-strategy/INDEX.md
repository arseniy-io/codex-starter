# Product Strategy

Методы для B2B SaaS с ролями, подписками, интеграциями и security-рисками.

## Методы

- [`saas-scope-boundary.md`](./saas-scope-boundary.md) - отделить MVP, архитектурный задел и будущий enterprise.
- [`integration-risk-map.md`](./integration-risk-map.md) - оценить интеграцию до попадания в roadmap.
- [`security-by-design-check.md`](./security-by-design-check.md) - проверить фичу через данные, роли, audit log и edge cases.

## Как использовать

- Если фича расползается - читай `saas-scope-boundary.md`.
- Если обсуждается новая интеграция - читай `integration-risk-map.md`.
- Если есть данные пользователей, billing, роли или внешние API - читай `security-by-design-check.md`.
