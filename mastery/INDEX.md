# Mastery

Mastery - справочная папка с экспертными линзами: методами признанных авторов, практиков и школ мышления для нужных проекту областей.

Это не Codex skills. Skills запускают reusable workflow, а `mastery/` даёт контекст для мышления и решений.

Codex не должен читать всю папку целиком. Для каждой задачи сначала открывай этот индекс, затем индекс нужной области и только 1-3 релевантных авторских файла.

## Как устроено

- одна папка = одна область;
- один файл = один автор, практик или школа мышления;
- внутри файла автора - 1-3 сильных метода с пошаговым применением;
- это не пересказ книг, статей или курсов.

## Области

Список появится по мере заполнения после `POST_AUTOPILOT.md`.

Не создавай область или авторский файл ради полноты. Добавляй только тот метод, который нужен для реальной задачи проекта.

## Карточка источника

Для каждого используемого метода укажи:

1. Источник: автор, название и ссылка или библиографические данные.
2. Дату публикации или обновления, если она известна, и дату своей проверки.
3. Точное место: страница, раздел, глава, таймкод или фрагмент ссылки.
4. Уровень уверенности: высокий, средний или низкий, с короткой причиной.

Если этих данных нет, пометь метод как непроверенный и не основывай на нём рискованное решение. Храни короткий пересказ метода, а не длинную копию источника.

## Правило качества

Каждый авторский файл должен отвечать на вопросы:

1. Кто автор и почему его методам можно доверять.
2. Какие 1-3 метода стоит брать у этого автора.
3. Когда применять каждый метод.
4. Как применить метод по шагам.
5. Где границы метода и когда он не подходит.
6. Заполнена ли карточка источника и не устарела ли она.
