# Mastery

Mastery - справочная папка с методологиями, экспертными подходами и рабочими алгоритмами.

Это не Codex skills. Skills запускают reusable workflow, а `mastery/` даёт контекст для мышления и решений.

Codex не должен читать всю папку целиком. Для каждой задачи выбирай только нужную область и нужные файлы.

## Как устроено

- одна папка = одна область;
- один файл = один автор, метод или подход;
- внутри файла должны быть конкретные шаги применения, а не пересказ книги.

## Области

Добавляются по мере необходимости.

Примеры:

- `copywriting/`
- `negotiations/`
- `financial-analysis/`
- `product-strategy/`
- `decision-making/`

## Правило качества

Каждый файл должен отвечать на три вопроса:

1. Что это за метод.
2. Когда его применять.
3. Как применить по шагам.
