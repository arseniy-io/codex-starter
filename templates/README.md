# Templates

Codex использует файлы отсюда как образцы во время онбординга.

## AGENTS.md.tmpl

Шаблон для финального `AGENTS.md`, который создаётся на шаге 9 AUTOPILOT. Плейсхолдеры:

- `{{PROJECT_NAME}}` - название проекта;
- `{{PROJECT_ONE_LINER}}` - одно предложение о проекте;
- `{{STACK}}` - стек;
- `{{LANGUAGE_RULE}}` - язык общения.

## codex-config.toml.example

Консервативный пример project config. Его не нужно копировать целиком: бери только те настройки, которые действительно нужны проекту, и сверяй актуальную схему с официальными docs Codex.
