# Mastery Author Lenses

## Задача

Привести `mastery/` к модели авторских экспертных линз, не ломая общую структуру AUTOPILOT / POST_AUTOPILOT.

## Решение

- `mastery/` остаётся слоем методологий и экспертных подходов.
- Корневая структура остаётся прежней: `mastery/INDEX.md`, `mastery/README.md`, папки областей.
- Внутри области меняется правило: один файл = один автор или признанный практик.
- Внутри файла автора хранится 1-3 применимых метода: суть, шаги, когда применять, ограничения.
- Первый POST_AUTOPILOT по-прежнему создаёт только одну стартовую область, чтобы не раздувать шаблон.

## Файлы

- `mastery/INDEX.md`
- `mastery/README.md`
- `POST_AUTOPILOT.md`
- `AGENTS.md`
- `templates/AGENTS.md.tmpl`
- `README.md`
- `STRUCTURE.md`

## Проверки

- [x] Нет правила `один файл = один метод`.
- [x] POST_AUTOPILOT создаёт область через авторов, а не отдельные чеклисты.
- [x] Starter не содержит тестовую `mastery/product-strategy/` как рабочий контекст.
- [x] Навигация по-прежнему требует читать индекс и только 1-3 релевантных файла.
