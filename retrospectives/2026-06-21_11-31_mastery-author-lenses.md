# Mastery Author Lenses

## Что сделали

Перевели `mastery/` с модели "один файл = один метод" на модель "один файл = один автор, практик или школа мышления".

## Почему

Авторская модель лучше соответствует исходной идее `mastery/`: Codex должен применять конкретные экспертные линзы, а не просто набор разрозненных чеклистов.

## Важное решение

Структуру starter не меняли радикально:

- `mastery/INDEX.md` остаётся входной картой;
- область остаётся подпапкой;
- `POST_AUTOPILOT.md` всё ещё создаёт одну стартовую область;
- внутри области теперь создаются авторские файлы с 1-3 методами.

## Проверка

- Убраны активные правила про "один файл = один метод".
- Удалён тестовый рабочий контекст `mastery/product-strategy/`.
