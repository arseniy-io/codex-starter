# Уведомления и hooks Codex

**Когда брать:** после онбординга, если хочешь слышать/видеть, когда Codex закончил или ждёт решения.
**Что делает:** проверяет доступные уведомления в твоей поверхности Codex и, при необходимости, готовит hook-команду по официальной схеме.
**Результат:** понятный способ уведомлений без переноса старых настроек из других агентов.

## Почему так

Codex может работать в разных поверхностях: CLI, IDE, desktop app, web/cloud. Уведомления зависят от поверхности, поэтому сначала проверяем встроенные возможности, а hooks подключаем только по актуальной документации.

## Промпт

```prompt
Настрой мне уведомления Codex для текущей поверхности.

Действуй так:
1. Определи, где я работаю: CLI, IDE extension, desktop app или web/cloud.
2. Если есть встроенные уведомления - объясни, где их включить.
3. Если нужны hooks - открой официальную документацию Codex hooks и предложи минимальную настройку.
4. Не добавляй непроверенную схему config/hook. Если формат не удалось подтвердить, остановись и скажи, что именно надо проверить вручную.
5. После настройки дай микротест: короткая задача, после которой должно быть уведомление.

Всегда объясняй каждый изменённый файл одной строкой: что изменил и почему.
```

## Проверка

Задай микрозадачу: «посчитай 2+2 и закончи». После ответа должно быть понятно, что Codex завершил работу или ждёт пользователя.
