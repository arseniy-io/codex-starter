# Установка Codex skills с аудитом

**Когда брать:** после онбординга, когда нужен reusable workflow.
**Что делает:** помогает безопасно добавить локальные repo-skills или личные skills.
**Результат:** skill установлен только туда, где он действительно нужен.

## Что такое skill

Skill - это папка с `SKILL.md`, которую Codex может использовать для повторяемого workflow: дизайн, работа с PDF, деплой, QA, исследование и т.д.

Уровни:

- **Локально в репозитории:** `.agents/skills/` - подходит для project-specific workflows.
- **Лично для пользователя:** `$CODEX_HOME/skills/` или путь, который использует твоя установка Codex.

Правило: ставь локально, если skill нужен только этому проекту. Глобально - только то, чем пользуешься часто.

## Аудит перед установкой

Проверь:

1. `README.md` - что делает skill.
2. `SKILL.md` - какие инструкции он добавляет.
3. Скрипты - нет ли чтения `.env`, отправки данных наружу, удаления файлов, запуска неизвестных бинарников.
4. Лицензию и автора.
5. Нужен ли skill постоянно или хватит одноразового промпта.

## Промпт-аудит

```prompt
Я хочу установить skill по ссылке [URL].

Сначала скачай/прочитай исходники и проверь:
- README.md
- SKILL.md
- все shell/python/js-скрипты
- команды, которые читают `.env`
- внешние URL, curl/wget/fetch
- удаление или массовое перемещение файлов
- установку бинарников или postinstall scripts

Дай вердикт: безопасно / подозрительно / опасно.
Если безопасно, предложи куда ставить: `.agents/skills/` или личный `$CODEX_HOME/skills/`.
Если подозрительно или опасно - не устанавливай.
```

## Установка локального skill

```prompt
Установи этот skill локально в `.agents/skills/[skill-name]/`.

Требования:
1. Не трогай глобальные skills.
2. Сохрани README/SKILL.md и нужные assets/scripts.
3. После установки покажи дерево папки.
4. Объясни одной строкой, по какому триггеру skill должен использоваться.
```

## Финальная проверка

```prompt
Покажи дерево `.agents/skills/` и перечисли каждый локальный skill:
- название;
- когда использовать;
- какие файлы или scripts он может запускать;
- есть ли риск для секретов или filesystem.
```
