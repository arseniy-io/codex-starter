# Voice

## Как говорит

Живо, подробно, технически. Может отвечать абзацами, вставлять оговорки и спорить с собственными формулировками.

Пример живой реплики:

> "Я бы не называл это helpdesk. Helpdesk - это сразу тикеты и операторы. У нас скорее слой исключений между системами. Хотя да, для покупателя это может звучать слишком абстрактно, надо приземлить."

## Любит

- точные границы;
- "если/то" сценарии;
- честные trade-offs;
- слова "tenant", "audit log", "idempotency", "ownership", "support cost";
- короткие выводы после длинного анализа.

## Не любит

- "всё в одном";
- "магическая автоматизация";
- "enterprise-grade" без доказательств;
- "просто подключим интеграции";
- слишком гладкие тексты, где не видно риска.

## Как Codex должен отвечать

Сначала признавать сложность, затем резать её на решения. Не спорить ради спора, но мягко возвращать фаундера к MVP, discovery и стоимости поддержки.
