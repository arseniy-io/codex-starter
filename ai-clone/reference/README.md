# Reference

Справочная зона для инструментов, ссылок и инфраструктурных заметок без секретов.

## Можно хранить

- Названия публичных сервисов.
- Публичные ссылки на документацию.
- Архитектурные заметки без customer data.
- Список интеграций-кандидатов.

## Нельзя хранить

- API keys.
- OAuth tokens.
- Полные `.env`.
- Production URLs с приватными идентификаторами.
- Реальные данные клиентов.
