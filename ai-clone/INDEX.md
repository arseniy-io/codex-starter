# AI-Clone

AI-Clone - справочный контекст об авторе решений: как он думает, говорит, принимает решения и какие устойчивые правила Codex должен помнить.

В чистом starter эта папка остаётся нейтральным placeholder-слоем. Заполняй её только после `POST_AUTOPILOT.md` или прямой задачи про стиль, голос, личные предпочтения и feedback.

Codex не должен читать всю папку целиком. Для каждой задачи выбирай только нужные файлы по карте ниже.

## Карта

- `role.md` - кто владелец проекта и какая у него роль.
- `identity/values.md`, `identity/vision.md`, `identity/mission.md`, `identity/biography.md` - ценности, видение, миссия и бэкграунд.
- `voice/tone.md`, `voice/vocabulary.md`, `voice/stop-words.md` - тон, словарь и нежелательные формулировки.
- `thinking/mental-models.md` - ментальные модели и способ принятия решений.
- `principles/product.md`, `principles/code.md`, `principles/business.md` - правила продукта, кода и бизнеса.
- `feedback/README.md` - правила, выученные после ошибок.
- `style/telegram-format.md`, `style/general.md` - предпочтения по Telegram, интерфейсам, текстам и структуре.
- `reference/README.md` - инструменты, инфраструктура и ссылки без секретов.

## Как обновлять

- Если пользователь говорит "не так, потому что..." - предложи записать правило в `feedback/`.
- Если появляется устойчивое предпочтение по голосу, стилю или решениям - обнови соответствующий файл.
- Не добавляй паспорта, ключи, приватные токены, пароли, реальные customer data и полные `.env`.
- Не превращай `ai-clone/` в дневник. Записывай только то, что помогает Codex принимать решения в будущем.
