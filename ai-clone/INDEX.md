# AI-Clone

AI-Clone - справочный контекст о владельце SyncDesk: как он думает, говорит, принимает решения и какие ошибки уже запретил повторять.

Codex не должен читать всю папку целиком. Для каждой задачи выбирай только нужные файлы по карте ниже.

## Карта

- `role.md` - кто владелец проекта и какая у него роль.
- `identity/README.md` - ценности, амбиции, профессиональная рамка.
- `voice/README.md` - тон, словарь, спорные формулировки, стиль общения.
- `thinking/README.md` - ментальные модели и способ принятия решений.
- `principles/README.md` - правила продукта, кода, бизнеса и безопасности.
- `feedback/README.md` - правила, выученные после ошибок.
- `style/README.md` - предпочтения по интерфейсам, текстам и структуре.
- `reference/README.md` - инструменты, инфраструктура и ссылки без секретов.

## Как обновлять

- Если фаундер говорит "не так, потому что..." - предложи записать правило в `feedback/`.
- Если появляется устойчивое предпочтение по голосу, стилю или решениям - обнови соответствующий файл.
- Не добавляй паспорта, ключи, приватные токены, пароли, реальные customer data и полные `.env`.
- Не превращай `ai-clone/` в дневник. Записывай только то, что помогает Codex принимать решения в будущем.
