# AI-Clone

AI-Clone - справочный контекст о владельце проекта: как он думает, говорит, принимает решения и какие ошибки уже запретил повторять.

Codex не должен читать всю папку целиком. Для каждой задачи выбирай только нужные файлы по карте ниже.

## Карта

- `role.md` - кто владелец проекта и какая у него роль.
- `identity/README.md` - ценности, миссия, биография, долгосрочные цели.
- `voice/README.md` - тон, словарь, стоп-слова, стиль общения.
- `thinking/README.md` - ментальные модели и способ принятия решений.
- `principles/README.md` - правила продукта, кода и бизнеса.
- `feedback/README.md` - правила, выученные после ошибок.
- `style/README.md` - форматы текстов, визуальные предпочтения, оформление.
- `reference/README.md` - инструменты, инфраструктура и ссылки без секретов.

## Как обновлять

- Если пользователь говорит "не так, потому что..." - предложи записать правило в `feedback/`.
- Если появляется устойчивое предпочтение по голосу, стилю или решениям - обнови соответствующий файл.
- Не добавляй паспорта, ключи, приватные токены, пароли и полные `.env`.
