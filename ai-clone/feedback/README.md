# Feedback

Здесь живут правила, выученные через ошибки.

## Формат правила

```md
# Короткое название правила

## Rule

Что делать или не делать.

## Why

Почему это важно. Какая ошибка была.

## How to apply

Когда применять правило.
```

Не записывай сюда каждую мелочь. Добавляй только то, что должно пережить текущий чат.
