# План: PROJECT_STATE как короткий вход для Codex

## Цель

Сделать один короткий файл-вход, который помогает Codex в новом контекстном окне быстро понять проект и не читать лишние папки.

Важно: это не новая библиотека, а навигатор по уже существующим знаниям.

## Принцип

- Добавлять маленькими шагами.
- После каждого шага проверять, что starter не раздулся.
- Не менять сразу весь `POST_AUTOPILOT.md`.
- Сначала улучшить первую часть `AUTOPILOT.md`.
